# 日月塔罗｜小红书小程序版

这是 `tarot-site` 的小红书原生小程序版本，使用 `XHSML + CSS + JavaScript`，不依赖 React、npm 包或远程服务。

## 已实现

- 78 张完整塔罗牌与本地图片资源
- 感情、事业、财富、健康、综合五类问题
- 单张牌、时间之流、凯尔特十字三种牌阵
- 洗牌、切牌、发牌和正逆位抽取
- 逐张翻牌、完整解读和本地保存
- 浅色/深色主题
- 小红书站内分享、朋友圈与微信群分享回调
- 娱乐与专业建议免责声明

## 在开发者工具中打开

1. 在小红书开放平台创建一个“非交易型”小程序，并取得 24 位小程序 ID。
2. 下载并登录小红书小程序开发者工具。
3. 选择“导入项目”，项目目录选择本文件夹 `xhs-miniapp/`。
4. 在开发者工具中选择刚创建的小程序。工具会生成或更新本机的 `project.config.json`。
5. 编译后从首页依次测试：选择领域 → 洗牌 → 选择牌阵 → 翻牌 → 查看解读。

项目没有提交任何真实小程序 ID、密钥或账号信息。

## 同步牌面数据

网页版本的牌面文案仍以 `src/data/tarotCards.ts` 为唯一来源。修改后在仓库根目录运行：

```bash
npm run xhs:data
```

脚本会重新生成 `xhs-miniapp/data/tarot.js`。
